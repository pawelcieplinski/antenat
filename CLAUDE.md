# CLAUDE.md

Shared instructions for all agents live in `AGENTS.md`, imported below. They cover the language rule (everything in the repository and on GitHub is in English), the branch rule (changes reach `main` only through pull requests), the `.ai/` directory (SDD specs, task run logs, lessons) and the required workflow: read lessons at task start, append a run log entry in every commit, record a lesson after non-obvious fixes.

Record project lessons in `.ai/lessons/`, not in Claude Code memory (`~/.claude/projects/.../memory`).
