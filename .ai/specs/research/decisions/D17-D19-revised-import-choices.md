# D17–D19 — Revised choices for the import, after reading the spec

- Date, owner: 2026-11-14, Paweł Ciepliński (founder, product owner)
- Context: the founder read the spec `.ai/specs/2026-11-12-gedcom-import-ancestors-view.md` (PR #5) and corrected it in the chat. Verbatim: "Nie usuwaj żadnych danych z pliku przy imporcie. Możesz zapytać o to, czy importować dane kontaktowe, ale domyślnie tak. Repozytorium będzie prywatne, więc to ograniczenie jest niepotrzebne. Gedcom w dowolnej wersji o ile to możliwe." (quote; translation: "Don't remove any data from the file on import. You can ask whether to import contact data, but yes by default. The repository will be private, so that restriction is unnecessary. GEDCOM in any version, as far as possible.") The same message asked for the ancestors view to show all generations by default, with an optional control; that is a spec-level choice and has no row in the brief.
- Decisions:
  - D17 (supersedes D12): GEDCOM files are kept on the server as uploaded, nothing removed. At import, an option to import contact data is on by default; turning it off removes the contact data (e-mail, phone, addresses) of presumed-living and unknown-status people. That the option covers these people only, and the stored file as well as the records, is the agent's reading of "whether to import contact data", stated to the founder for correction.
  - D18 (supersedes D15): the import accepts GEDCOM files of any version, as far as possible. A file with an unknown version is read as 5.5.1 with a warning.
  - D19: the repository is to become private. It is public on 2026-11-14 (checked with `gh repo view`), so until it is private no personal data from family trees is committed; that condition is the agent's, because git history keeps a file after visibility changes.
- Consequences, and what would make us revisit them: D17 means Antenat stores living relatives' contact data by default, which makes Q07 weigh more before release to other users; revisit when Q07 is answered. D18 adds legacy encodings (ANSEL, ANSI) and the `.gdz` archive to the reader. D19 lifts the synthetic-only rule for tests once the repository is private.
- Status: active (D17–D19)
